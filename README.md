# F.R.I.D.A.Y. AI Assistant

**Movie-grade continuously learning AI companion**

Inspired by Iron Man’s FRIDAY.  
Full PC control tools • Real code sandbox • Skill learning • Creative generation (games + dancing characters) • Designed for 4GB GPUs.

---

## Start in 30 seconds

1. Clone or download this repo
2. Double-click the start button:

| System          | Start Button        |
|-----------------|---------------------|
| **Windows**     | `start_friday.bat`  |
| **macOS/Linux** | `./start_friday.sh` |

That’s it. The first run installs everything automatically.

Full guide → **[SETUP.md](SETUP.md)**

## What she can do

```
You > make a dancing cartoon character named Nova
You > make a robot style dancing character
You > make a pong game / breakout game / dodge game
You > list files
You > system info
You > list processes
You > remember that my name is Tony
You > skills
You > what do you remember
You > open https://github.com
```

### Core features

- Natural, calm, slightly witty conversation (never robotic)
- Continuous learning – every success becomes a reusable skill
- Real isolated code sandbox with timeout
- Expanded PC control (files, terminal, processes, open URLs)
- Real playable pygame games generated on demand
- Real dancing cartoon GIFs (cute / robot / iron / neon styles)
- Persistent memory that survives restarts
- Lightweight – runs on 4GB graphics cards and even CPU-only machines
